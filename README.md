# うさぎ学童保育所 リニューアル提案デモ

ピンクと白を基調に、既存サイトのロゴ・キャラクター・活動写真を使って一から制作した非公開デモです。実在の施設の公式サイトではなく、施設からの制作承認・素材利用許諾を示すものでもありません。公開サーバーへのアップロードは行っていません。

## 開き方

`index.html` を Edge / Chrome などの現行ブラウザーで開いてください。インストール・ビルド・インターネット接続は不要です。外部の既存サイトへのリンクを開く場合は通信が発生します。

## 構成

- index.html：施設紹介、くらし、ブログ、利用案内、FAQ、見学の操作デモ
- style.css：ピンクと白のデザイン、スマホ・タブレット・PC表示
- script.js：メニュー、スケジュール切替、ブログ絞り込み、記事詳細、フォーム操作
- assets/：既存サイトから取得した画像7点
- 参考情報.md：参照元・素材一覧・情報の扱い
- 動作確認.md：検証結果と確認範囲
- preview-top.png / preview-mobile-top.png：PC・スマホ幅の上部プレビュー
- preview-desktop.png / preview-mobile.png：全体プレビュー

## 操作できること

スマホメニューの開閉、平日／休日のスケジュール切替、行事／運動あそびのブログ絞り込み、記事の全文表示、FAQの開閉、見学相談の操作体験に対応しています。記事は閉じるボタン・Escape・背景クリックで閉じられます。タブは左右キー・Home・Endでも切り替えられます。

## デモの範囲

利用案内の対象児童・対象校・時間・所在地は、既存サイトの公開情報を参考に記載しています。最新性は未確認のため、現行条件の確定案内ではありません。料金は既存サイトを確認する導線にしています。

紹介文・記事本文・一日のスケジュールは提案用です。ブログは固定のサンプル3本で、投稿用の管理画面はありません。写真を新しい活動報告として扱っていません。児童の氏名、発言、活動日時などを新たに付け加えていません。

見学フォームは選択式の操作体験です。個人情報を収集せず、予約・メール送信・サーバー保存は行いません。JavaScriptが無効な場合、フォームの実行ボタンは無効のままです。

外部フォント・解析ツール・外部ライブラリは使用していません。ページの表示や操作はローカルで完結します。デモにはnoindex,nofollowを指定していますが、これは閲覧制限ではありません。

## 画像について

利用者からの「非公開のデモで既存写真・キャラクターを使う」という指示に基づき取り込みました。権利は各権利者に帰属します。非公開であることだけで著作権や肖像の許諾が不要になるという意味ではありません。公開・外部配布する場合は施設と権利者に素材の利用範囲、児童写真の同意状況、掲載情報を確認してください。

AI生成画像・初版のオリジナルSVGは今回のデモには使っていません。既存写真は元データが640×120pxの組み写真のため、高解像度の原本より画質に制約があります。
