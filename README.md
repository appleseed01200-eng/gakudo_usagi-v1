# うさぎ学童保育所 リニューアル提案デモ

ピンクと白のデザイン、既存サイトのロゴ・キャラクター・活動写真を使った非公開の提案デモです。12の独立したHTMLページで構成しています。実在の施設の公式サイトではなく、制作承認・素材利用許諾を確認済みという意味ではありません。公開サーバーへのアップロードは行っていません。

## 開き方

`index.html`をEdge / Chromeなどの現行ブラウザーで開いてください。インストール・ビルド・インターネット接続は不要です。リンクから別のHTMLページへ移動できます。外部サイトやGoogleマップへのリンクを開く場合は通信が発生します。

## ページ構成

| ファイル | 内容 |
| --- | --- |
| index.html | ホーム・各ページへの入口・日記の新着カード |
| about.html | 学童について・居場所の考え方・保育方針の提案 |
| life.html | 平日／学校が休みの日の一例・学習・おやつ・遊び |
| events.html | 四季・12か月の行事例・参加前の確認事項 |
| team.html | 指導員と家庭の関わり・連絡・保護者の関わり方 |
| admission.html | 対象・時間・元サイト掲載の保育料表・手続きの例 |
| journal.html | 日記一覧・行事／運動あそびの絞り込み |
| journal-camp.html | 行事の記事サンプル |
| journal-sports.html | 運動の記事サンプル |
| journal-ball.html | ボール遊びの記事サンプル |
| faq.html | 利用・暮らし・見学など12問のFAQ |
| contact.html | 見学の確認ポイント・アクセス・相談の操作デモ |

ヘッダーとフッターから各ページへ移動できます。下層ページにはパンくずを設けています。日記はカードのデザインを残し、記事本文も独立ページにしました。記事から一覧へ戻れます。

## フォント

見出しはZen丸ゴシック（Bold）、本文はNoto Sans JP（可変フォント）です。`assets/fonts/`に実ファイルを同梱しているため、オフラインで表示できます。端末のOSへフォントをインストールする必要はありません。フォントはSIL Open Font Licenseに基づくもので、同梱フォルダ内に各OFLライセンスを保存しています。

日本語のフォント一式を含むため、初回の読み込みやZIPの容量が以前より増えています。外部のフォント配信サービスへの通信はありません。

## 実際の情報と提案内容

うさぎ学童の既存サイトから、対象児童・対象校・保育時間・所在地・電話番号・掲載料金を参考にしています。更新日や現在の適用条件は未確認です。入所案内の金額は「元サイト掲載額」と明記しています。

保育の考え方、年間行事、一日の時間割、入所手続き、紹介コピーは構成を確認するための提案例です。うさぎ学童の正式な方針・年間計画・実施実績とは区別しています。指導員の氏名・資格・人数や保護者の体験談は創作していません。

日記の写真は既存サイト掲載のものですが、記事本文は提案用のサンプルです。撮影日時や行事名は未確認で、最新の活動報告ではありません。児童の氏名・発言等を新たに付け加えていません。

見学フォームは選択式の操作体験です。個人情報の収集、予約、メール送信、サーバー保存は行いません。JavaScriptが無効でも本文・記事リンクは読めますが、スケジュールの切替や絞り込みは利用できません。フォームの実行ボタンは無効のままです。スマホメニューが使えない場合も、各ページ末尾の全ページリンクから移動できます。

## ファイルの編集

各HTMLを直接編集して本文を更新できます。共通デザインはstyle.cssとpages.css、動作はscript.jsです。日記の記事本文はjournal-*.htmlにあります。共通のヘッダー・フッターは各ページに静的に含めているため、ナビゲーションを変更する際は全ページへ反映してください。CMSや投稿管理画面はありません。

## 画像・公開について

ユーザー指定の非公開の提案用途で、既存写真・キャラクターを取り込んでいます。画像の権利は各権利者に帰属します。公開・外部配布時は、施設・権利者に素材の利用範囲や児童写真の同意状況を確認してください。noindex,nofollowは検索除外の指定で、閲覧制限ではありません。

既存の写真は640×120pxの組み写真なので、画質に元データによる制約があります。素材の一覧と参照元は「参考情報.md」をご覧ください。動作確認の範囲は「動作確認.md」に記載しています。
